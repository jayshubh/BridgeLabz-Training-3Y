# JavaScript Practice

Solutions are grouped by subject and assignment. Each console exercise is a
standalone `.js` file; the browser exercises include a matching `.html` file
that loads the JavaScript beside it.

## Topics

- `gcr-codebase/javascript-basics/assignment-1/` — conditions, values, arrays,
  operators, and loops
- `gcr-codebase/javascript-basics/assignment-2/` — scope, strings, arrays, and
  Boolean logic
- `gcr-codebase/javascript-basics/assignment-3/` — conversion, validation,
  strict mode, hoisting, errors, and JSON
- `gcr-codebase/classes-and-forms/assignment-4/` — classes, objects, and forms
- `gcr-codebase/functions-and-prototypes/assignment-5/` — callbacks, closures,
  prototypes, and inheritance
- `gcr-codebase/asynchronous-javascript/assignment-6/` — Promises, timers,
  async/await, and the event loop
- `gcr-codebase/dom-interactivity/assignment-7/` — events, forms, and DOM

## Run

Run a console exercise with Node.js from the repository root, for example:

```powershell
node javascript-practice/gcr-codebase/javascript-basics/assignment-1/q1.js
```

Open an assignment's `.html` file in a browser to try its interactive exercise.
The product-fetch exercise in Assignment 6 needs an internet connection.
