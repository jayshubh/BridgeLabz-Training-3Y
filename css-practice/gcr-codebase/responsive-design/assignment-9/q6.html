Question 6 - Responsive CSS cheat sheet

Responsive CSS, at a glance

Filters

Visual adjustments without editing the source image.

filter: grayscale(1);

Media Queries

Apply rules when the viewport matches a condition.

@media (max-width: 700px)

Responsive Design

Layouts that adapt to the space and device available.

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

Typography

Fluid type keeps reading comfortable at every size.

font-size: clamp(1rem, 2vw, 1.5rem);
